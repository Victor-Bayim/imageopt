# Source provenance

The implementation was restored on 2026-11-15 from the project source snapshot
supplied by the repository owner. `provenance/restored-source.json` records the
original source hashes. The previous public main commit was
`e17f078ad38b7dd5ca9535c3934e523c4961a50c`.

The repository owner's stated role is independent implementation of sampling,
selection, application and evaluation. Existing copyright and SPDX headers are
retained, including the BPF source's GPL declaration. This restoration does not
assign a new blanket MIT license to all files or to third-party dependencies.
Consult individual file headers and dependency licenses before redistribution.

The portable validation tools, synthetic selector fixture/demo and interpreter
portability change are maintenance additions. They are not additional historical
performance measurements. Historical aggregates and raw preserved observations
are identified separately in `benchmarks/historical/`.
